# elem

A dead simple command line utility for quick lookup of periodic table elements

## Summary

Designed for people who spend a lot of time working in a shell (and also a little time working with the periodic table), `elem` retrieves the proton number, symbol, and name of an element when you can only remember one of those three pieces of information.

The project source code is written in C.

## Example Usage

```bash
$ elem he
2       He      Helium
$ elem 8
8       O       Oxygen
$ elem uranium
92      U       Uranium
$ elem 41 kr silver
41      Nb      Niobium
36      Kr      Krypton
47      Ag      Silver
```
